English 800｜職場有聲英文 PWA 第一版
====================================

這是可在 iPhone 加到主畫面的網頁 App 原型，不是已簽署的 iOS .ipa 原生安裝包。
功能：
- 6 篇多益／科技業英文課程
- 英文朗讀、慢速播放、繁體中文朗讀（使用裝置系統語音）
- 單字搜尋、熟悉度標記
- 多益風格小測驗與答題統計
- 學習紀錄存在目前瀏覽器／裝置的 localStorage
- PWA 快取，部署後可支援部分離線使用

重要限制：
- 語音品質與可用聲音取決於 iOS / Safari 系統語音，不是專業錄製音檔。
- 學習紀錄目前只存在本機，不會自動同步到其他裝置。
- 測驗為練習題，不等同正式多益模擬考或分數預測。
- 此版本沒有登入、雲端資料庫、AI 對話或語音發音評分。

部署方式（需要一次性 HTTPS 網址）：
1. 解壓縮 ZIP。
2. 將全部檔案上傳至支援靜態網站與 HTTPS 的服務，例如 GitHub Pages、Netlify 或 Cloudflare Pages。
3. 開啟部署後的 HTTPS 網址，確認首頁能正常顯示。
4. iPhone 用 Safari 開啟該網址。
5. 點「分享」→「加入主畫面」→「加入」。
6. 從主畫面點 English 800 圖示即可像 App 一樣開啟。

若只把 ZIP 傳到手機檔案 App，不能直接安裝成原生 iPhone App；PWA 必須先透過 HTTPS 網址開啟並加入主畫面。

若要真正上架 App Store：
需要 macOS + Xcode、Apple Developer 帳號、原生 SwiftUI 專案或合適的包裝方案、簽署與測試流程。這份 ZIP 不是可直接上架的 IPA。
